# Graduate-ML-Final-Project
Deep Learning- U-Net vs. Autoencoder Image Segmentation

## Context
This workflow was developed for the final project in UT Austin's Graduate Subsurface Machine Learning Course. While the professor, [Dr. Michael Pyrcz](https://www.pge.utexas.edu/faculty-and-staff/michael-pyrcz/), hosts all student projects on his [GitHub](https://github.com/GeostatsGuy) in the [Machine Learning Course](https://github.com/GeostatsGuy/MachineLearningCourse/blob/main/2025b_MLProjects/UnetVAutoencoder_Rhiannon_Morris.ipynb) repository, this repository contains solely my individual work. 

## Method & Skills
 - Compared image segmentation performance of a simple U-Net to a simple autoencoder for educational purposes. 
 - Evaluated models using Intersection over Union (IoU), weighted Cross-Entropy Loss, and pixel-wise accuracy.
 - Implemented PyTorch, NumPy, and Matplotlib. 

 ## Results
 - Demonstrated that the simple U-Net architecture outperforms the simple autoencoder in an image segmentation task due to the presence of skip connections that preserve fine spatial details during dimensionality reduction.
